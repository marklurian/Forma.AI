# Forma.AI 🏋️‍♂️

Forma.AI is a web app that acts as your personal AI fitness coach. Instead of scrolling through random workout plans, you just input your goals, experience level, and the equipment you have at home or the gym. The app then uses AI to generate a complete, customized workout schedule with sets, reps, and rest times.

## Tech Stack
- **Next.js** (App Router, TypeScript)
- **Tailwind CSS**
- **Groq API** (for the AI brain)
- **Vercel** (for hosting)

---

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
